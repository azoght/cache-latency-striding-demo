Conceptual Cache Latency vs. Stride and Block Size

Interactive 3D surface showing an illustrative (not measured) average-latency model as a function of stride (bytes) and block size (cache line size, bytes). Use the sliders to change the number of sets and associativity (ways). Spikes appear when (stride / block) mod sets ≈ 0, causing repeated mapping to the same set (conflict thrash). Higher associativity reduces spike amplitude.
